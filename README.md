# San_Francisco_Bike_Projections
EDA and Supporting code for a project which models the forecasting and demand of Bike-Sharing and Rental in San Francisco.

I explore the dataset using R to understand fundamental relationships and feature interactions. Subsequently, we construct and compare two distinct modeling approaches in Python: a time series approach using SARIMAX and a machine learning regression approach using Histogram-based Gradient Boosting. The report outlines the rationale for model selection, mathematical formulations, and a final comparative evaluation.
